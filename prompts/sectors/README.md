# SolidDesign Sector Overlays

Sector overlays are **conditional heuristics**, not separate design frameworks.

## Current state

No sector overlay is canonical in prompt architecture v0.1.

Do not invent one merely because a prospect belongs to a recognizable profession or trade.

## Promotion rule

A sector file may be added only when the same commercially meaningful design pattern has recurred across multiple real prospects and has proved useful enough to justify a shared heuristic.

A future sector overlay should remain small and answer questions such as:

- which customer intents are unusually important in this sector?
- which trust signals repeatedly matter?
- which conversion action repeatedly deserves higher priority?
- which content/navigation pattern repeatedly reduces friction?

It must not become a full template, visual theme or second prompt architecture.

## Loading rule

Load a sector overlay only when:

1. the file already exists in this directory; and
2. it is clearly relevant to the current prospect.

Prospect-specific variation otherwise remains in the customer project and Prospect Design Brief.
