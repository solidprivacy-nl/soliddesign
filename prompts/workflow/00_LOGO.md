# Workflow 00 — Optional Logo Redesign

## Scope

Run this workflow only when the current user explicitly requests **LOGO_AND_WEBSITE** work.

This workflow owns logo diagnosis, redesign and asset locking only. It does not contain a second website-design method. After the logo is locked, continue with the canonical SolidDesign Design Bootstrap and its required website resources.

## Goal

Improve the existing logo while preserving valuable recognition, then lock one exact final logo asset that becomes the identity input for the website redesign.

## 1. Diagnose the current logo

Assess:

- recognition and distinctiveness;
- relevance and audience/category fit;
- legibility and small-size performance;
- silhouette/icon strength;
- typography, kerning and spacing;
- geometry and balance;
- one-color performance;
- dark/light background behavior;
- digital header/favicon suitability;
- overall professional craft.

Classify meaningful logo elements as:

- **PRESERVE**;
- **REPAIR / EVOLVE**;
- **REMOVE**;
- **ADD** only when a concrete problem requires it.

## 2. Identify equity anchors

Explicitly identify what creates recognition, for example:

- silhouette or icon;
- letter/monogram shape;
- name structure and capitalization;
- signature color;
- characteristic angle or spacing;
- wordmark rhythm;
- icon/wordmark relationship.

Classify each anchor:

**must preserve / may evolve / may remove**

## 3. Choose the smallest justified intervention

### A. Refinement / refresh
Use when the concept is sound and craft is the problem.

### B. Evolutionary redesign
Use when the identity should visibly improve while remaining recognizably related.

### C. Replacement
Use only when the existing concept is strategically wrong or unusable.

Default bias:

> **evolution before replacement**

Do not redesign a logo merely because it looks old.

## 4. Explore before finalizing

Internally consider conservative, evolutionary and progressive directions.

Do not expose weak variants simply because they were generated. Select the strongest direction that solves the diagnosed problem with the least unnecessary loss of recognition.

## 5. Refine the selected direction

Check:

- typography and custom letterforms where justified;
- kerning/tracking/optical spacing;
- silhouette;
- geometry and balance;
- stroke consistency and counter shapes;
- black/white performance;
- small-size performance;
- dark/light background performance;
- website-header use.

Reject:

- generic AI symmetry;
- meaningless icon fusion;
- unnecessary gradients;
- excessive simplification;
- arbitrary hidden meanings;
- generic sector clichés;
- a new identity that loses valuable recognition without a documented reason.

## 6. Logo acceptance gate

The new logo must:

- solve a stated problem;
- preserve valuable equity or deliberately discard it for a documented reason;
- remain distinctive and legible;
- work at small sizes;
- work conceptually in one color;
- have controlled typography and spacing;
- function in a website header;
- be materially better than the existing logo.

If not, refine again.

## 7. Lock the exact final asset

Create and lock:

**`LOGO_FINAL_01`**

Requirements:

- high-resolution PNG;
- preferably transparent background;
- clean edges;
- no unnecessary outer whitespace;
- suitable for desktop/mobile header use.

Once locked, do not redraw, regenerate or approximate it later. Do not change spacing, colors or typography between the standalone logo artifact and the website.

The exact `LOGO_FINAL_01` is the only redesigned logo asset used by the subsequent website workflow.

## Handoff to website design

After `LOGO_FINAL_01` is locked:

1. load the canonical SolidDesign Design Bootstrap;
2. treat `LOGO_FINAL_01` as the approved/locked logo for its website-only identity boundary;
3. use the same Design Constitution and workflows 01–04 as every other SolidDesign website redesign;
4. do not copy website rules into this logo workflow.
