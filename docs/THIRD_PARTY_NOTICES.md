# Third-Party Notices

SolidDesign may reuse or adapt open-source software. This file records required attribution for code actually incorporated into this repository.

## Current state

At documentation baseline, no substantial third-party source tree has yet been vendored into this repository.

Donor candidates and licenses are tracked in `docs/DONOR_REGISTER.md`.

When code is copied or vendored, add the exact upstream copyright and license notice here and retain any notices required by the donor license.

## Rules

1. A README badge is not sufficient provenance; inspect the actual license file.
2. Record source commit SHA for copied code where practical.
3. Do not copy proprietary code.
4. Do not assume a root project license covers unrelated bundled assets/plugins.
5. Record generated-asset rights separately when applicable.
